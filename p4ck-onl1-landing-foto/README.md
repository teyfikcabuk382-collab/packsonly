# P4ck Onl1 — Landing page

Archivos para publicar en GitHub y desplegar en Vercel.

- `index.html`: página principal.
- `images/portada.jpg`: foto proporcionada para la landing.
- `vercel.json`: configuración sencilla para Vercel.

Sube todos los archivos y la carpeta `images` a la raíz del repositorio. En Vercel importa el repositorio y selecciona el preset **Other**; no requiere build command ni output directory.
